# Milk Track & Cost

**ACTIVE CAPSULE CONTEXT**



• **User Intent**: The user wants to build a mobile app that tracks their daily milk consumption and calculates the total cost at the end of the month. The app should have a calendar feature where the user can mark the days they consume milk and note the days they skip milk with a reason.



• **Key decisions made**: The user has decided to build a mobile app to track their daily milk consumption and has received 10 free credits for their first prompt.



• **Constraints or requirements identified**: The app should have a calendar feature, allow users to mark days they consume milk, note days they skip milk with a reason, calculate the total cost at the end of the month, and reset the total cost at the start of each month. The app should also display a list of every month with the total cost of milk and allow users to view the calendar for each month.



• **Technicalities/Details**: The app will be built using a mobile app framework, and the user will implement a calendar feature, a consumption tracking feature, and a cost calculation feature. The app will also have a section to display the total cost of milk for each month and allow users to view the calendar for each month.
